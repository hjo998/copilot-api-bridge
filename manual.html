1. 이게 뭐야?

회사에서 GitHub Copilot만 허용되는 상황에서, VS Code 안에서만 쓸 수 있는 Copilot AI를
다른 프로그램(Python 스크립트, 웹앱, 자동화 도구 등)에서도 사용할 수 있게 해주는 다리(Bridge)입니다.

전체 아키텍처

requests / openai
→
🔌 API Bridge
localhost:3141
→
🤖 Copilot LM API

📄 DocReview 웹앱
브라우저 (doc-reviewer.html)
→
🖥️ serve.py
역프록시 :8080
→
🔌 API Bridge
localhost:3141
→
🤖 Copilot LM
claude-opus-4.6

위: 스크립트에서 직접 호출  /  아래: 웹앱(DocReview)에서 역프록시 경유
모든 통신은 내 PC 안에서만 (네트워크 노출 없음)

OpenAI API와 100% 같은 형식으로 동작합니다.
openai Python 라이브러리를 그대로 사용하고, base_url만 바꾸면 됩니다.

3. 설치 방법 (최초 1회)

  1. 터미널 열기 VS Code에서 Ctrl + ` (백틱)으로 터미널을 엽니다.
  2. 확장 빌드
    powershell cd tools\copilot-api-bridge npm install npm run compile
  3. VS Code에 확장 연결
    powershell (관리자) # PowerShell을 "관리자 권한"으로 실행: $extDir = "$env:USERPROFILE\.vscode\extensions\local.copilot-api-bridge-0.1.0" $target = "<워크스페이스 경로>\tools\copilot-api-bridge" New-Item -ItemType Junction -Path $extDir -Target $target
    이미 존재한다는 오류가 나면 이미 설치된 것입니다.
  4. VS Code 재시작 완전히 닫았다가 다시 열면, 하단 상태바에 📡 API:3141 표시.
  5. 첫 동의 (1회만) 첫 API 호출 시 VS Code 상단에 Language Model 사용 동의 팝업 → "Allow" 클릭.

5. 새 프로젝트에서 AI 사용하기

아무 프로젝트에서든 3단계면 AI를 붙일 수 있습니다:

  1. openai 라이브러리 설치
    bash pip install openai
  2. 클라이언트 설정 (코드 2줄)
    python from openai import OpenAI client = OpenAI( base_url="http://127.0.0.1:3141/v1", # ← 이것만 바꾸면 됨 api_key="not-needed" # ← 아무 값이나 OK )
  3. AI 호출
    python response = client.chat.completions.create( model="claude-opus-4.6", messages=[ {"role": "system", "content": "도움이 되는 AI 어시스턴트입니다."}, {"role": "user", "content": "안녕하세요!"} ] ) print(response.choices[0].message.content)
핵심: 기존 OpenAI API 코드가 있다면 base_url과 model만 바꾸면 바로 동작합니다.

복사해서 쓰는 헬퍼 템플릿

python — 새 프로젝트 시작 템플릿 """ Copilot API Bridge 헬퍼 사전 조건: VS Code에서 확장이 실행 중이어야 함 """ from openai import OpenAI client = OpenAI(base_url="http://127.0.0.1:3141/v1", api_key="not-needed") def ask_ai(prompt: str, system: str = "도움이 되는 AI 어시스턴트입니다.") -> str: response = client.chat.completions.create( model="claude-opus-4.6", messages=[ {"role": "system", "content": system}, {"role": "user", "content": prompt} ] ) return response.choices[0].message.content # 사용 print(ask_ai("Python에서 리스트 컴프리헨션이 뭐야?"))

6. 코드 예시 (실전)

Word 문서를 AI로 리뷰하기

python from openai import OpenAI import docx # pip install python-docx client = OpenAI(base_url="http://127.0.0.1:3141/v1", api_key="x") # 1. Word 문서 텍스트 추출 doc = docx.Document("report.docx") text = "\n".join(p.text for p in doc.paragraphs if p.text.strip()) # 2. AI에게 리뷰 요청 response = client.chat.completions.create( model="claude-opus-4.6", messages=[ {"role": "system", "content": """기술 문서 리뷰어입니다. 다음 관점에서 리뷰하세요: 1. 논리적 일관성 2. 누락된 내용 3. 문법/맞춤법 4. 개선 제안"""}, {"role": "user", "content": f"다음 문서를 리뷰해주세요:\n\n{text}"} ] ) print(response.choices[0].message.content)

문서 번역

python from openai import OpenAI client = OpenAI(base_url="http://127.0.0.1:3141/v1", api_key="x") def translate(text, target_lang="English"): r = client.chat.completions.create( model="claude-opus-4.6", messages=[ {"role": "system", "content": f"전문 번역가입니다. {target_lang}로 자연스럽게 번역합니다. 기술 용어는 유지합니다."}, {"role": "user", "content": text} ] ) return r.choices[0].message.content print(translate("배터리 에너지 저장 시스템(BESS)의 용량 산정 방법론을 설명합니다."))

데이터 분석

python from openai import OpenAI import pandas as pd client = OpenAI(base_url="http://127.0.0.1:3141/v1", api_key="x") df = pd.read_excel("data.xlsx") summary = df.describe().to_string() r = client.chat.completions.create( model="claude-opus-4.6", messages=[ {"role": "system", "content": "데이터 분석 전문가. 핵심 인사이트를 한국어로 정리."}, {"role": "user", "content": f"주요 특징과 인사이트:\n\n{summary}"} ] ) print(r.choices[0].message.content)

Streamlit 웹앱 + AI 채팅

python — app.py import streamlit as st from openai import OpenAI client = OpenAI(base_url="http://127.0.0.1:3141/v1", api_key="x") st.title("AI 어시스턴트") if "messages" not in st.session_state: st.session_state.messages = [] for msg in st.session_state.messages: with st.chat_message(msg["role"]): st.write(msg["content"]) if prompt := st.chat_input("질문을 입력하세요"): st.session_state.messages.append({"role": "user", "content": prompt}) with st.chat_message("assistant"): r = client.chat.completions.create( model="claude-opus-4.6", messages=st.session_state.messages ) answer = r.choices[0].message.content st.write(answer) st.session_state.messages.append({"role": "assistant", "content": answer})

실행: streamlit run app.py

7. 실전 적용 — DocReview 기술문서 리뷰 콘솔

Copilot API Bridge의 첫 번째 실전 활용 사례입니다.
영문 기술문서(Word .docx)를 브라우저에서 열고, AI가 문법·오타·맥락·상충을 섹션 단위로 검토합니다.

DocReview란?

항목내용
목적BESS 영문 기술문서의 AI 기술 리뷰 (문법/표현/맥락/상충)
사용자엔지니어 / 테크니컬 라이터 (비개발자)
입출력.docx 업로드 → 섹션별 AI 리뷰 → 제안 텍스트 복사
LLM 연결serve.py 역프록시 → Copilot API Bridge (:3141)

실행 방법

  1. Copilot API Bridge가 실행 중인지 확인 VS Code 하단에 API:3141 표시 확인
  2. DocReview 서버 시작
    powershell cd projects\docreview pip install -r requirements.txt python serve.py --port 8080 --api http://127.0.0.1:3141

    또는 start.bat 더블클릭 (Windows)

  3. 브라우저에서 접속 http://localhost:8080 접속 → .docx 파일 업로드 → "리뷰 시작"
서버 역할: serve.py는 정적 HTML 서빙 + /v1/* 요청을 API Bridge로 역프록시합니다.
브라우저 → serve.py(:8080) → API Bridge(:3141) → Copilot. CORS 문제가 원천 해소됩니다.

프로젝트 구조

text projects/docreview/ ├── serve.py ← Python 역프록시 서버 (정적 파일 + /v1 프록시) ├── start.bat ← Windows 원클릭 실행 ├── requirements.txt ← python-docx ├── Caddyfile ← 운영 배포용 리버스 프록시 설정 ├── web/ │ └── doc-reviewer.html ← 단일 파일 SPA (mammoth.js로 docx 파싱) └── docs/ ├── CONTEXT.md ← 결정 히스토리 (필독) ├── DEPLOY.md ← 서버 배포 레시피 ├── HANDOFF.md ← 완료/미완료/다음 단계 └── PROMPT.md ← 리뷰 프롬프트 설계 노트

9. 자주 묻는 질문

VS Code를 닫으면 API도 꺼지나요?
네. VS Code가 열려 있어야 합니다. 최소화해두면 됩니다.
다른 PC에서 접근할 수 있나요?
API Bridge 자체는 아닙니다 (localhost 전용).
단, DocReview의 serve.py는 0.0.0.0으로 리슨하므로 같은 네트워크 PC에서 http://<서버IP>:8080으로 접속 가능합니다.
동시에 여러 요청을 보내도 되나요?
가능하지만 Copilot rate limit이 있으므로 배치 처리 시 1-2초 간격 권장.
어떤 모델을 쓸 수 있나요?
현재 claude-opus-4.6 1개. curl http://127.0.0.1:3141/v1/models로 확인.
회사 보안 정책에 문제없나요?
  • 내 PC 안에서만 동작 (네트워크 노출 없음)
  • 이미 허용된 Copilot 계정 사용
  • 추가 외부 서비스 연결 없음
단, "프로그래밍 방식 접근" 정책은 조직마다 다르므로 확인 필요.
"No Copilot models available" 오류
  1. GitHub Copilot 확장 설치 확인
  2. Copilot 로그인 확인 (좌측 하단)
  3. VS Code 재시작
  4. Copilot 구독 유효 확인
응답이 중간에 잘리는 경우
모델 출력 토큰 제한. 긴 문서는 섹션별로 나누거나, "간결하게" 지시 추가.
DocReview에서 "502 Bad Gateway" 에러
serve.py가 API Bridge에 연결 실패. 확인 순서:
  1. VS Code에서 API Bridge 실행 중? (API:3141 표시)
  2. serve.py 실행 시 --api http://127.0.0.1:3141 올바른지?
  3. 포트 충돌 없는지?
